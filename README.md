# 🗺️ Gemini programming隊 専用：DOM操作・画面切り替えシステム 取扱説明書

このシステムは、`R.js` および `rg.js` のメモリ空間（スロット）を利用して、HTML画面を動的に登録・切り替えるためのコア・モジュールである。

---

## 🛠️ 基本仕様
- **モジュール名**: `DomHtml(htmlContent, name)`
- **役割**: HTML文字列を関数として `R.js` の空きスロット（配列 `_`）に登録する。
- **依存関係**: 
    - `R.js` (配列 `_` と `Rs()` 関数)
    - `rg.js` (`Rg()` 関数)
    - `main.js` (`missionLog()`, `updateMetaTags()`)

---

## 🚀 使い方（コマンド一覧）

### 1. 画面（ページ）を登録する
新しい画面を作成したい時は、`DomHtml` を呼び出す。空いている最小のインデックス番号を自動で探し、そこに「画面切り替え関数」をインストールする。

```javascript
// 例：ポケモンクエストの「図鑑画面」を登録
const pokedexIdx = DomHtml(`
    <div class="screen">
        <h1>🔍 ポケモン図鑑</h1>
        <p>ここで持っているポケモンのデータを確認できます。</p>
        <button onclick="Rg(0)()">ホームに戻る</button>
    </div>
`, "PokedexView");
```

### 2. 画面を切り替える（実行）

登録時に受け取ったインデックス番号、または Rg(番号) を使って呼び出す。

```JavaScript
// インデックス番号を使って呼び出し
Rg(pokedexIdx)("図鑑を開いたログ");

// 直接スロットを指定して呼び出し（番号がわかっている場合）
// _[1]();
```
# 🛰️ ミッションログ（動作フロー）
画面が切り替わると、以下のプロセスが自動で走る。

DOMの置換: `document.body.innerHTML` が渡されたHTMLで上書きされる。

ログ出力: `[DOM_CHANGE]` ログがコンソールに送られ、遷移元のタイトルや追加データが記録される。

メタ情報の更新: [ロゴ](https://kakaomames.github.io/rei/logo.png)とタイトルが再セットされる。

# ⚠️ 隊員への注意事項
イベントの初期化: `innerHTML` で書き換えるため、既存のDOMに設定していた `addEventListener` は消失する。

対策: インライン（onclick="..."）を使うか、切り替え関数内で再度リスナーを貼る処理を追加すること。

インデックス管理: `DomHtml` は実行されるたびに新しいスロットを消費する。初期化時に一度だけ実行するのが望ましい。
