# 🗺️ Gemini programming隊 専用： 取扱説明書

このシステムは、`R.js` および `rg.js` のメモリ空間（スロット）を利用して、HTML画面を動的に登録・切り替えるためのコア・モジュールである。

---

## 🛠️ 基本仕様
- **モジュール名**: `DomHtml(htmlContent, name)`
- **役割**: HTML文字列を関数として `R.js` の空きスロット（配列 `_`）に登録する。
- **依存関係**: 
    - `R.js` (配列 `_` と `Rs()` 関数)
    - `rg.js` (`Rg()` 関数)
    - `main.js` (`missionLog()`, `updateMetaTags()`)

---

## 🚀 使い方（コマンド一覧）

### 1. 画面（ページ）を登録する
新しい画面を作成したい時は、`DomHtml` を呼び出す。空いている最小のインデックス番号を自動で探し、そこに「画面切り替え関数」をインストールする。

```javascript
// 例：ポケモンクエストの「図鑑画面」を登録
const pokedexIdx = DomHtml(`
    <div class="screen">
        <h1>🔍 ポケモン図鑑</h1>
        <p>ここで持っているポケモンのデータを確認できます。</p>
        <button onclick="Rg(0)()">ホームに戻る</button>
    </div>
`, "PokedexView");
```

### 2. 画面を切り替える（実行）

登録時に受け取ったインデックス番号、または Rg(番号) を使って呼び出す。

```JavaScript
// インデックス番号を使って呼び出し
Rg(pokedexIdx)("図鑑を開いたログ");

// 直接スロットを指定して呼び出し（番号がわかっている場合）
// _[1]();
```
# 🛰️ ミッションログ（動作フロー）
画面が切り替わると、以下のプロセスが自動で走る。

DOMの置換: `document.body.innerHTML` が渡されたHTMLで上書きされる。

ログ出力: `[DOM_CHANGE]` ログがコンソールに送られ、遷移元のタイトルや追加データが記録される。

メタ情報の更新: [ロゴ](https://kakaomames.github.io/rei/logo.png)とタイトルが再セットされる。

# ⚠️ 隊員への注意事項
イベントの初期化: `innerHTML` で書き換えるため、既存のDOMに設定していた `addEventListener` は消失する。

対策: インライン（onclick="..."）を使うか、切り替え関数内で再度リスナーを貼る処理を追加すること。

インデックス管理: `DomHtml` は実行されるたびに新しいスロットを消費する。初期化時に一度だけ実行するのが望ましい。

# Gemini programming隊 共有ライブラリ取扱説明書 (R.js / rg.js)

このドキュメントは、当探検隊で使用するデータ管理用スクリプト `R.js` および `rg.js` の仕様をまとめたものである。

## 1. R.js (Data Storage & Initialization)
グローバルなデータ格納庫 `_`（アンダースコア）を管理し、システムの初期化を行う。

### 構成変数
* `_`: データを保持する配列。
* `R`: `_` への参照。

### 主要機能
* **v()**: システムの初期化関数。
    * 変数 `r` の初期化ログを `missionLog` に出力する。
    * 謎の呪文（あうあう）を含む文字列計算を行い、起動準備を整える。
* **Rs(c, o)**: インストール関数。
    * `_[c]` に対してオブジェクト `o` を格納する。
    * 完了時にコンソールへ `R: [Installed！]` と出力する。
* **a()**: エントリポイント。内部で `v()` を呼び出す。

---

## 2. rg.js (Data Registry)
`R.js` で管理されているデータにアクセスするためのゲッター関数を提供する。

### 主要機能
* **Rg(c)**: 取得関数。
    * `R.js` 内の配列 `_` から、指定されたインデックス `c` の値を返す。

---

## 3. 使用方法（ミッション・ガイド）

### データの登録 (R.js)
新しいデータやモジュールを登録する際は `Rs` を使用する。
```javascript
// 例: 隊員名簿を登録
Rs(0, { name: "カカオマメ", role: "隊員" });
```
### データの取得 (rg.js)

登録されたデータを呼び出す際は `Rg` を使用する。

```JavaScript
// 例: 0番目のデータを取得
const member = Rg(0);
missionLog("DATA", "隊員情報を照会", member.name);
```
### 起動シーケンス

システム開始時に 50 行の空行を生成し、コンソールをクリーンにしてから a() を実行せよ。

## 4. 探検隊ログ (System Log)
本ライブラリは `missionLog` 関数と連携し、常に以下のステータスを報告する。

`[SYSTEM]` rの初期化完了！

`R: [Installed！]`
